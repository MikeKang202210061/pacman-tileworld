# Pac-Man Tileworld

A Pac-Man-inspired exploration game set in a procedurally generated tile world. Each seeded world contains connected rooms, corridors, collectible coins, and persistent game state.

## Features

- Procedurally generated rooms and corridors from a seed
- Keyboard-controlled player movement
- Collectible coins and completion tracking
- Menu-driven new-game, save, and load workflows
- Tile-based rendering and interactive keyboard controls

## My contribution

I worked primarily on the menu and interaction flow, player mechanics, save/load system, and integration through the main entry point, with additional world-state work.

## Attribution

## Run

The entry point is `core.Main`. Compile the source with the required Java drawing dependencies, then launch the main class.
